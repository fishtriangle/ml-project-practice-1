## О проекте

В репозитории выполнен полный цикл разведочного анализа медицинского датасета о пациентах
с первичным билиарным циррозом. Цель работы — понять структуру данных, оценить их качество,
очистить от клинически невозможных значений, выявить статистические и клинические
закономерности, влияющие на исход наблюдения (выживание / трансплантация / смерть).

Результат работы — единый Jupyter-ноутбук `project.ipynb` с восемью тематическими частями
и итоговым блоком выводов, а также шаблон интерактивного Streamlit-дашборда.

## Датасет

- **Название:** Multi-Class Prediction of Cirrhosis Outcomes
- **Источник:** Kaggle Playground Series S3E26
  (https://www.kaggle.com/competitions/playground-series-s3e26)
- **Первоисточник:** UCI Machine Learning Repository, *Cirrhosis Patient Survival Prediction*
- **Объём:** ~7 700 строк × 19 столбцов
- **Целевая переменная:** `Status` с тремя классами
  - `C` — пациент жив на момент окончания наблюдения (цензурирован)
  - `CL` — пациент жив благодаря трансплантации печени
  - `D` — пациент умер
- **Признаки:** возраст, пол, принимаемый препарат, лабораторные показатели
  (билирубин, альбумин, медь, щелочная фосфатаза, AST, холестерин, триглицериды,
  тромбоциты, протромбиновое время), клинические признаки (асцит, гепатомегалия,
  сосудистые «паучки», отёки), гистологическая стадия фиброза.

## Стек технологий

- **Язык:** Python 3.10+
- **Анализ:** pandas, numpy, scipy
- **Визуализация:** matplotlib, seaborn
- **Survival-анализ:** lifelines (Kaplan-Meier, log-rank)

- **Автоотчёты:** ydata-profiling
- **Интерактив:** streamlit
- **Данные:** kagglehub

## Установка и запуск

### 1. Установка зависимостей

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Дополнительные пакеты, которые ставятся прямо в ноутбуке через `!pip install`:

```bash
pip install lifelines phik ydata-profiling streamlit kagglehub
```

### 2. Авторизация в Kaggle

Перед первым запуском создайте API-токен на https://www.kaggle.com/settings/api
и сохраните его как `~/.kaggle/kaggle.json` либо выполните в ноутбуке:

```python
import kagglehub
kagglehub.login()
```

### 3. Скачивание датасета

В ячейке блока **1.2** раскомментируйте вызов `kagglehub.competition_download` —
архив будет распакован в `./data/`.

### 4. Запуск ноутбука

```bash
jupyter notebook project.ipynb
```

Выполняйте ячейки последовательно сверху вниз. Ячейки с `!pip install` можно
пропускать, если зависимости уже установлены.

### 5. Streamlit-дашборд

Ноутбук сохраняет файл `cirrhosis_dashboard.py` через магию `%%writefile`.
Для запуска:

```bash
streamlit run cirrhosis_dashboard.py
```

Дашборд будет доступен на `http://localhost:8501`.

### 6. HTML-отчёт ydata-profiling

После выполнения блока **7.2** в корне проекта появится файл
`cirrhosis_eda_report.html` — откройте его в браузере.

## Ключевые выводы

1. **Целевая переменная `Status` несбалансирована** — класс `CL` встречается редко
   (< 3 %), что требует взвешенных метрик и стратификации при разбиении выборок.
2. **Лабораторные признаки сильно скошены вправо** (`Bilirubin`, `Copper`, `Alk_Phos`,
   `SGOT`) — обязательны `log1p`-преобразования перед линейными моделями.
3. **`Stage` согласуется с клиническими показателями**: чем выше стадия, тем выше
   медианные `Bilirubin`, `Copper`, `Prothrombin` и ниже `Albumin`, `Platelets`.
4. **Kaplan-Meier кривые по стадиям статистически значимо разделяются** (log-rank
   `p < 0.05`) — `Stage` является сильным прогностическим признаком.
5. **Мультиколлинеарность** между `SGOT ↔ Alk_Phos` и `Bilirubin ↔ Copper` требует
   регуляризации или отбора признаков перед линейными моделями.
6. **Формальные IQR-выбросы — это реальные тяжёлые пациенты**, а не ошибки ввода.
   Прямое удаление по правилу 1.5·IQR недопустимо; корректная стратегия — log-преобразование
   и устойчивые метрики (MAD, percentile rank).

## Методология анализа

Работа построена по классической схеме EDA — от проверки качества к одномерному,
многомерному и сегментированному анализу:

- **Качество данных:** пропуски, дубликаты, биологически невозможные значения,
  клинические диапазоны, согласованность категориальных признаков, формальные
  статистические выбросы (IQR, z-score, MAD).
- **Одномерный анализ:** описательные статистики, гистограммы + KDE, violin/box,
  QQ-plot, тесты нормальности, частоты категориальных признаков.
- **Survival-специфика:** Kaplan-Meier кривые и log-rank тест по `Status` и `Stage`
  (методы, отсутствующие в базовых matplotlib/seaborn).
- **Многомерный анализ:** pairplot, корреляция Пирсона, матрица φk (phik) —
  универсальная мера связи для смешанных типов признаков.
- **Сегментированный анализ:** сравнение профилей стадий и групп исхода через
  radar chart на percentile rank.
- **Автоматизация:** ydata-profiling как чек-лист, Streamlit-дашборд для интерактивного
  исследования подгрупп.
